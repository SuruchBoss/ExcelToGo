# ExcelToGo

เว็บแอปที่แปลงตาราง Excel ให้กลายเป็น UI ที่กรอกง่ายสำหรับคนทั่วไป มีสูตรสำเร็จรูปให้ลากวางแทนการจำสูตรเอง
มีผู้ช่วย AI ที่แนะนำสูตรจากคำอธิบายภาษาไทย/อังกฤษ และส่งออกกลับเป็นไฟล์ Excel หรือ PDF ได้ทันที

สร้างด้วย **Next.js (App Router) + TypeScript** ตามที่ต้องการ รันได้ทั้งในเครื่องตัวเองและ deploy ขึ้นเว็บได้ฟรีผ่าน Vercel

## Tech Stack

### Framework / ภาษา
| เทคโนโลยี | เวอร์ชัน | ใช้ทำอะไร |
|---|---|---|
| [Next.js](https://nextjs.org) | 16 (App Router) | เฟรมเวิร์กหลักของเว็บแอป ทั้งหน้าเว็บ (client component) และ API route (`/api/ai/formula`) |
| [React](https://react.dev) | 19 | UI library |
| [TypeScript](https://www.typescriptlang.org) | 5 | type safety ทั้งโปรเจกต์ รวมถึงเอนจินคำนวณสูตรที่เขียนเอง |
| [Tailwind CSS](https://tailwindcss.com) | 4 | จัดสไตล์ทั้งหมดแบบ utility-class |

### ไลบรารีหลักที่ใช้
| ไลบรารี | ใช้ทำอะไร |
|---|---|
| `exceljs` | อ่านไฟล์ `.xlsx` ที่ผู้ใช้อัปโหลด และสร้างไฟล์ `.xlsx` ตอนส่งออก (คงสูตรเดิมไว้ในไฟล์ที่ export) |
| `jspdf` + `jspdf-autotable` | สร้างไฟล์ PDF จากตารางที่คำนวณค่าแล้ว |
| `@anthropic-ai/sdk` | เชื่อมต่อ Claude API สำหรับผู้ช่วย AI แนะนำสูตร |
| `lucide-react` | ไอคอนในหน้า UI |
| `clsx` | รวม className แบบมีเงื่อนไข |

> **หมายเหตุ:** ไม่ได้ใช้ไลบรารีคำนวณสูตรสำเร็จรูป (เช่น HyperFormula) แต่เขียน **เอนจินคำนวณสูตรขึ้นเอง**
> (`src/lib/formulaEngine/`) ทั้ง tokenizer, parser, evaluator และฟังก์ชันต่างๆ เพื่อควบคุมพฤติกรรม
> เช่นการอ้างอิงเซลล์ (`A1`, `A1:B10`), การตรวจ circular reference, และการเลื่อนสูตรแบบ relative/absolute
> เวลา "ใส่สูตรให้ทั้งแถว/คอลัมน์" (เหมือนการลาก fill handle ใน Excel) ได้เอง รวมถึงเลี่ยงปัญหาลิขสิทธิ์/ช่องโหว่
> ความปลอดภัยของไลบรารีสำเร็จรูปบางตัว

### เครื่องมือ (Tools)
- **Node.js 18.18+** (แนะนำ Node 20 หรือ 22) และ **npm**
- **ESLint 9** (`eslint-config-next`) สำหรับตรวจโค้ด
- **Git** สำหรับ clone/push โค้ด
- ไม่ต้องใช้ฐานข้อมูลหรือ backend แยก — ทุกอย่างรันอยู่ใน Next.js เดียว (state ของตารางอยู่ใน browser memory ระหว่างใช้งาน ยังไม่มีระบบบันทึกลงคลาวด์)

## วิธีดึงไปใช้งาน

### 1) รันในเครื่องตัวเอง (Local Development)

```bash
# 1. โคลนโปรเจกต์
git clone https://github.com/SuruchBoss/ExcelToGo.git
cd ExcelToGo

# 2. ติดตั้ง dependencies
npm install

# 3. รันเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

เปิดเบราว์เซอร์ไปที่ **http://localhost:3000** จะเห็นตารางตัวอย่างพร้อมใช้งานทันที ไม่ต้องตั้งค่าอะไรเพิ่ม

คำสั่งอื่นๆ ที่มีให้:

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run dev` | รันโหมดพัฒนา (hot reload) |
| `npm run build` | build เป็นเวอร์ชัน production |
| `npm run start` | รันเวอร์ชันที่ build แล้ว (ต้อง `npm run build` ก่อน) |
| `npm run lint` | ตรวจสอบคุณภาพโค้ดด้วย ESLint |

### 2) ตั้งค่าผู้ช่วย AI ให้ใช้ Claude จริง (ไม่บังคับ)

ค่าเริ่มต้น ผู้ช่วย AI จะแนะนำสูตรจาก **การจับคำสำคัญในเครื่อง** (ทำงานได้ทันทีโดยไม่ต้องตั้งค่าอะไร)
แต่ถ้าต้องการให้ AI ตีความคำถามภาษาธรรมชาติได้แม่นยำและยืดหยุ่นกว่าเดิม ให้เชื่อมต่อกับ Claude API:

```bash
# คัดลอกไฟล์ตัวอย่าง
cp .env.example .env.local
```

แล้วเปิด `.env.local` ใส่ค่า:

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxx
```

(ขอ API key ได้ที่ [console.anthropic.com](https://console.anthropic.com)) จากนั้นรัน `npm run dev` ใหม่
ระบบจะสลับไปใช้ Claude โดยอัตโนมัติเมื่อเจอค่านี้ — ไม่ต้องแก้โค้ดใดๆ

### 3) Deploy ขึ้นเว็บจริง

โปรเจกต์นี้เป็น Next.js มาตรฐาน จึง deploy ได้กับทุกแพลตฟอร์มที่รองรับ Next.js เช่น:

- **[Vercel](https://vercel.com)** (แนะนำ ง่ายสุด): เชื่อม repo GitHub นี้เข้ากับ Vercel แล้วกด Deploy ได้เลย
  ไม่ต้องตั้งค่าอะไรเพิ่ม ถ้าต้องการ AI จริงให้ไปเพิ่ม Environment Variable ชื่อ `ANTHROPIC_API_KEY`
  ในหน้า Project Settings → Environment Variables
- Self-host ด้วย Docker/Node server ทั่วไป: `npm run build` แล้วรันด้วย `npm run start` (ต้องตั้งค่า `ANTHROPIC_API_KEY`
  เป็น environment variable ของเซิร์ฟเวอร์ถ้าต้องการ AI จริง)

## ฟีเจอร์และวิธีใช้อย่างละเอียด

### 1. ตารางกรอกข้อมูล (Spreadsheet Grid)

- คลิกเซลล์เพื่อเลือก, **ดับเบิลคลิก** หรือกด **F2** เพื่อแก้ไขค่าในเซลล์
- พิมพ์ตัวอักษร/ตัวเลขขณะเลือกเซลล์ได้เลยโดยไม่ต้องดับเบิลคลิกก่อน (จะเริ่มพิมพ์ทับค่าเดิมทันที)
- ใช้ปุ่มลูกศร (arrow keys), **Enter** (ลงแถวถัดไป), **Tab** (ไปคอลัมน์ถัดไป) เพื่อเลื่อนเซลล์ที่เลือก
- กด **Delete/Backspace** เพื่อลบค่าของเซลล์ที่เลือก
- **เลือกทั้งช่วง** ได้ด้วยการลากเมาส์ หรือกด **Shift** ค้างแล้วคลิกเซลล์ปลายทาง
- **หัวแถว (ตัวเลข) และหัวคอลัมน์ (A, B, C, ...) จะถูกปักหมุด (sticky)** ไว้เสมอเวลาเลื่อนตารางที่มีข้อมูลเยอะๆ
  และ **ไฮไลต์สีฟ้า** ให้เห็นชัดว่ากำลังอยู่แถว/คอลัมน์ไหน — ออกแบบมาเพื่อแก้ปัญหา "เลื่อนจอแล้วงงว่าอยู่แถว/คอลัมน์ไหน"
  ที่มักเจอใน Excel ตารางใหญ่ๆ
- ปุ่ม **"+ แถว"** และ **"+ คอลัมน์"** บน toolbar ใช้ขยายขนาดตารางเพิ่มทีละแถว/คอลัมน์

### 2. นำเข้าไฟล์ Excel ที่มีอยู่แล้ว

1. กดปุ่ม **"นำเข้า Excel"** บน toolbar
2. เลือกไฟล์ `.xlsx` (หรือ `.xlsm`, `.xls`) จากเครื่อง
3. ระบบจะอ่านค่าทุกเซลล์ รวมถึง **สูตรเดิมที่มีอยู่แล้ว** เข้ามาแสดงในตารางทันที พร้อมคำนวณผลลัพธ์ใหม่

### 3. ใส่สูตรแบบลากวาง (ไม่ต้องจำสูตร)

กดปุ่ม **"สูตร"** บน toolbar เพื่อเปิดแถบสูตรด้านขวา ซึ่งมี:

- ช่องค้นหาสูตร และปุ่มกรองตามหมวดหมู่ (คณิตศาสตร์ / สถิติ / ตรรกะ / ข้อความ / วันที่ / ค้นหา)
- การ์ดสูตรแต่ละอัน แสดงชื่อ, syntax, คำอธิบาย และตัวอย่าง

**วิธีใส่สูตรมี 2 แบบ ทำแบบไหนก็ได้:**

- **ลากแล้ววาง**: ลากการ์ดสูตรจากแถบด้านขวา ไปวางบนเซลล์ที่ต้องการในตาราง (เซลล์จะไฮไลต์สีเขียวตอนลากผ่าน)
- **คลิกแล้วเลือก**: เลือกเซลล์ปลายทางในตารางก่อน แล้วคลิกที่การ์ดสูตร

ทั้งสองแบบจะเปิด **แผงกรอกพารามิเตอร์** ขึ้นมาทางขวา ให้กรอกค่าที่สูตรต้องการ (เช่น ช่วงเซลล์, เงื่อนไข)
สำหรับพารามิเตอร์ที่เป็น "เซลล์" หรือ "ช่วงเซลล์" จะมีปุ่มไอคอนเป้าเล็ง (🎯) ข้างช่องกรอก — กดปุ่มนี้แล้ว
**คลิกหรือลากเลือกเซลล์ในตารางได้เลยแทนการพิมพ์เอง** ที่อยู่เซลล์จะถูกเติมให้อัตโนมัติ พร้อมไฮไลต์แถว/คอลัมน์
ที่เลือกให้เห็นชัดเจน (แก้ปัญหาเรื่องงงว่าเลือกช่วงถูกไหม)

![แผงกรอกพารามิเตอร์สูตร SUM กำลังเลือกช่วง C2:C4 จากตาราง พร้อมตัวเลือกใส่สูตรให้ทั้งแถว/คอลัมน์/ช่วงที่เลือก](docs/screenshots/02-formula-panel.png)

ด้านล่างของแผงมีตัวเลือก **"ใส่สูตรนี้ให้กับ"**:
- **เซลล์นี้เท่านั้น** — ใส่ที่เซลล์เดียว
- **ทั้งแถว** — ใส่สูตร (ปรับอ้างอิงให้เหมาะสมอัตโนมัติ) ในทุกคอลัมน์ของแถวนั้น
- **ทั้งคอลัมน์** — ใส่สูตรในทุกแถวของคอลัมน์นั้น (เหมือนลาก fill handle ลงทั้งคอลัมน์ใน Excel)
- **ช่วงที่เลือกไว้** — ใส่สูตรทั่วทั้งช่วงเซลล์ที่เลือกไว้ก่อนหน้า (ใช้ได้เมื่อเลือกมากกว่า 1 เซลล์)

ระบบจะปรับการอ้างอิงเซลล์แบบ relative ให้อัตโนมัติเหมือน Excel (เช่นลาก `=A1*B1` ลงแถวถัดไปจะกลายเป็น `=A2*B2`)
ส่วนการอ้างอิงแบบ absolute (ใส่ `$` เช่น `$A$1`) จะไม่เลื่อนตาม

กดปุ่ม **"ใส่สูตร"** เพื่อยืนยัน หรือ **"ยกเลิก"** เพื่อปิดแผงโดยไม่ใส่ หลังกดใส่สูตร ผลลัพธ์จะคำนวณขึ้นในเซลล์ทันที:

![หลังกดใส่สูตร เซลล์ B6 แสดงผลลัพธ์ SUM(C2:C4) เป็น 100 ทันที](docs/screenshots/03-after-insert.png)

### 4. ถาม AI หาสูตร

กดปุ่ม **"ถาม AI"** บน toolbar เพื่อเปิดแถบผู้ช่วย AI ด้านขวา:

1. พิมพ์สิ่งที่ต้องการเป็นประโยคภาษาไทยหรืออังกฤษ เช่น
   - "อยากรวมยอดขายทั้งหมดในคอลัมน์นี้"
   - "หาค่าเฉลี่ยของคะแนนสอบ"
   - "ถ้าคะแนนมากกว่า 50 ให้ขึ้นว่า ผ่าน"
   - "ค้นหาราคาสินค้าจากรหัสสินค้า"
   (หรือกดปุ่มตัวอย่างคำถามที่มีให้ด้านล่างช่องพิมพ์)
2. กด **"ถาม AI"** (หรือกด Enter) ระบบจะส่งคำถาม พร้อมช่วงเซลล์ที่กำลังเลือกอยู่ ไปให้ AI แนะนำ
3. ผลลัพธ์จะแสดงสูตรที่แนะนำพร้อมคำอธิบายสั้นๆ
4. กด **"ใส่สูตรนี้ที่เซลล์ ..."** เพื่อใส่สูตรลงเซลล์ที่เลือกอยู่ทันที (ใส่ที่เซลล์เดียว — ถ้าต้องการลากทั้งแถว/คอลัมน์
   ให้ไปปรับที่แถบ "สูตร" แทนหลังใส่)

![แถบผู้ช่วย AI แสดงคำแนะนำสูตร =SUM(C2:C4) จากคำถาม "อยากรวมยอดขายทั้งหมดในคอลัมน์นี้"](docs/screenshots/04-ai-assistant.png)

> ถ้ายังไม่ได้ตั้งค่า `ANTHROPIC_API_KEY` ระบบจะแนะนำสูตรจากการจับคำสำคัญเบื้องต้นแทน (มีข้อความแจ้งใต้คำแนะนำเสมอ)
> ยังใช้งานได้ปกติ เพียงแต่แม่นยำน้อยกว่าการต่อ Claude จริง

### 5. ส่งออกไฟล์

- **ส่งออก Excel**: กดปุ่ม "ส่งออก Excel" จะได้ไฟล์ `.xlsx` ที่มีทั้งค่าที่คำนวณแล้วและ **สูตรต้นฉบับติดไปด้วย**
  (เปิดใน Excel/Google Sheets แล้วแก้ไขสูตรต่อได้ปกติ)
- **ส่งออก PDF**: กดปุ่ม "ส่งออก PDF" จะได้ไฟล์ PDF ของตาราง (แสดงเฉพาะค่าที่คำนวณแล้ว พร้อมหัวแถว/คอลัมน์)
  เหมาะสำหรับพิมพ์หรือส่งให้คนอื่นดูโดยไม่ต้องแก้ไข

## โครงสร้างโปรเจกต์

```
src/
  app/
    page.tsx                 # หน้าเว็บหลัก เชื่อม state ของตาราง + คอมโพเนนต์ทั้งหมดเข้าด้วยกัน
    api/ai/formula/route.ts  # API endpoint ให้ AI แนะนำสูตร (ใช้ Claude หรือ fallback)
  components/
    SpreadsheetGrid.tsx      # ตารางหลัก (เลือกเซลล์, แก้ไข, sticky header, drag-drop รับสูตร)
    FormulaPalette.tsx       # แถบรายการสูตร ค้นหา/กรองหมวดหมู่/ลากวาง
    FormulaParamPanel.tsx    # แผงกรอกพารามิเตอร์สูตร + เลือกช่วงจากตาราง + เลือก scope
    AIAssistantPanel.tsx     # แชทถาม AI หาสูตร
    Toolbar.tsx              # แถบเครื่องมือด้านบน (นำเข้า/ส่งออก/เพิ่มแถว-คอลัมน์/สลับแถบข้าง)
  lib/
    formulaEngine/           # เอนจินคำนวณสูตรที่เขียนเอง (tokenizer, parser, evaluator, functions)
    formulaCatalog.ts        # รายการสูตรสำเร็จรูปที่แสดงในแถบ "สูตร"
    aiHeuristic.ts           # ตรรกะแนะนำสูตรจากคำสำคัญ (ใช้เมื่อไม่มี ANTHROPIC_API_KEY)
    sheet.ts                 # โมเดลข้อมูลตาราง, คำนวณค่าทั้งชีต, ใส่สูตรตาม scope ต่างๆ
    excelIO.ts                # นำเข้า/ส่งออกไฟล์ .xlsx ด้วย exceljs
    pdfExport.ts              # ส่งออก PDF ด้วย jspdf + jspdf-autotable
  types/
    sheet-ui.ts               # types สำหรับ selection ของตารางฝั่ง UI
```

## รายการสูตรที่รองรับ

| หมวดหมู่ | สูตร |
|---|---|
| คณิตศาสตร์ | `SUM`, `PRODUCT`, `ROUND`, `ABS`, `SUMIF` |
| สถิติ | `AVERAGE`, `COUNT`, `COUNTA`, `MIN`, `MAX`, `COUNTIF`, `AVERAGEIF` |
| ตรรกะ | `IF`, `IFERROR`, `AND`, `OR` |
| ข้อความ | `CONCATENATE`, `UPPER`, `LOWER`, `TRIM`, `LEFT`, `RIGHT` |
| วันที่ | `TODAY`, `NOW` |
| ค้นหา | `VLOOKUP` |

เอนจินคำนวณยังรองรับการอ้างอิงเซลล์/ช่วงเซลล์ (`A1`, `A1:B10`), การอ้างอิงแบบ absolute (`$A$1`),
ตัวดำเนินการคำนวณ/เปรียบเทียบ/ต่อข้อความ (`+ - * / ^ = <> < > <= >= &`) และแจ้งค่า error แบบ Excel
เช่น `#DIV/0!`, `#VALUE!`, `#NAME?`, `#N/A`, `#CIRCULAR!` (กรณีสูตรอ้างอิงกันเป็นวงกลม)

ต้องการสูตรเพิ่มเติม? เพิ่มได้ที่ `src/lib/formulaEngine/functions.ts` (ตัวเอนจิน) และ `src/lib/formulaCatalog.ts`
(รายการที่แสดงในแถบสูตรพร้อมฟอร์มกรอกพารามิเตอร์)

## ปัญหาที่พบบ่อย

**Q: นำเข้าไฟล์ Excel แล้วขึ้น error ว่านำเข้าไม่ได้**
A: ตรวจสอบว่าไฟล์เป็น `.xlsx` ที่ไม่เสียหาย (ไฟล์ `.xls` แบบเก่ามากๆ หรือไฟล์ที่ล็อกรหัสผ่านอาจอ่านไม่ได้)

**Q: ผู้ช่วย AI ตอบแปลกๆ หรือแนะนำสูตรไม่ตรงที่ต้องการ**
A: ถ้ายังไม่ได้ตั้งค่า `ANTHROPIC_API_KEY` ระบบจะแนะนำจากคำสำคัญง่ายๆ เท่านั้น (จะมีข้อความแจ้งเตือนใต้คำตอบเสมอ)
ให้ตั้งค่า API key ตามขั้นตอนใน [หัวข้อที่ 2](#2-ตั้งค่าผู้ช่วย-ai-ให้ใช้-claude-จริง-ไม่บังคับ) เพื่อความแม่นยำที่ดีขึ้น

**Q: ใส่สูตรแล้วเซลล์ขึ้น `#CIRCULAR!`**
A: แปลว่าสูตรในเซลล์นั้นอ้างอิงกลับมาที่ตัวเองทางอ้อม (เช่น A1 อ้างถึง B1 และ B1 อ้างถึง A1) ให้แก้สูตรให้ไม่วนกลับ

**Q: ข้อมูลที่กรอกหายไปเมื่อรีเฟรชหน้าเว็บ**
A: ตอนนี้ตารางเก็บอยู่ใน memory ของเบราว์เซอร์ระหว่างใช้งานเท่านั้น (ยังไม่มีระบบบันทึกอัตโนมัติ) แนะนำให้กด
**"ส่งออก Excel"** เพื่อบันทึกงานเป็นไฟล์เก็บไว้ก่อนปิด/รีเฟรชหน้าเว็บ
