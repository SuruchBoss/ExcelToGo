# ExcelToGo

เว็บแอปสำหรับสร้าง/นำเข้าตาราง Excel ให้กลายเป็น UI ที่กรอกง่าย พร้อมสูตรสำเร็จรูปให้ลากวาง
และผู้ช่วย AI ที่ช่วยแนะนำสูตรจากคำอธิบายภาษาไทย/อังกฤษ แล้วส่งออกกลับเป็น Excel หรือ PDF ได้

## ฟีเจอร์หลัก

- **ตารางกรอกข้อมูลที่เป็นมิตร** — หัวแถว/คอลัมน์ถูกปักหมุด (sticky) และไฮไลต์แถว/คอลัมน์ที่กำลังเลือกอยู่เสมอ
  เพื่อไม่ให้หลงว่ากำลังอยู่แถวหรือคอลัมน์ไหนเวลาเลื่อนดูตารางใหญ่ๆ
- **สูตรพร้อมใช้แบบลากวาง** — เลือกสูตรจากแถบด้านข้าง (SUM, AVERAGE, IF, VLOOKUP ฯลฯ) ลากไปวางบนเซลล์
  หรือคลิกเพื่อเปิดแผงกรอกพารามิเตอร์ พร้อมปุ่ม "เลือกช่วงจากตาราง" ที่ให้คลิก/ลากเลือกเซลล์แทนการพิมพ์เอง
  และเลือกได้ว่าจะใส่สูตรนี้ให้กับเซลล์เดียว ทั้งแถว ทั้งคอลัมน์ หรือช่วงที่เลือกไว้
- **ผู้ช่วย AI หาสูตร** — พิมพ์สิ่งที่ต้องการเป็นภาษาพูด เช่น "อยากรวมยอดขายทั้งหมดในคอลัมน์นี้"
  ระบบจะแนะนำสูตรและคำอธิบายให้ พร้อมปุ่มใส่สูตรทันที
- **นำเข้า/ส่งออก** — นำเข้าไฟล์ `.xlsx` ที่มีอยู่แล้ว หรือส่งออกตารางที่แก้ไขกลับเป็น `.xlsx` (คงสูตรไว้)
  หรือ `.pdf` สำหรับพิมพ์/แชร์

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000)

### เปิดใช้ AI จริง (ไม่บังคับ)

ค่าเริ่มต้นผู้ช่วย AI จะแนะนำสูตรจากการจับคำสำคัญ (ทำงานได้โดยไม่ต้องตั้งค่าใดๆ)
หากต้องการให้ Claude ช่วยตีความคำถามได้แม่นยำขึ้น ให้คัดลอก `.env.example` เป็น `.env.local`
แล้วใส่ค่า `ANTHROPIC_API_KEY` ของคุณ

## เทคโนโลยีที่ใช้

- Next.js (App Router) + TypeScript + Tailwind CSS
- เอนจินคำนวณสูตรที่พัฒนาเอง (`src/lib/formulaEngine`) รองรับฟังก์ชันสไตล์ Excel
  เช่น SUM, AVERAGE, IF, VLOOKUP, SUMIF, COUNTIF และการอ้างอิงเซลล์/ช่วงเซลล์
- `exceljs` สำหรับนำเข้า/ส่งออกไฟล์ Excel, `jspdf` + `jspdf-autotable` สำหรับส่งออก PDF
- `@anthropic-ai/sdk` สำหรับผู้ช่วย AI (ใช้งานได้แม้ไม่ตั้งค่า API key โดยจะ fallback เป็นการจับคำสำคัญ)
